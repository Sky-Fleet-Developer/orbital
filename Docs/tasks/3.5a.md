# Задача 3.5a: CelestialProjection, размещение тела и порог «точка/диск»

Исполнитель: deepcode. Постановщик и приёмка: Claude (координатор). Контекст: `Docs/Stage3-Plan.md`, разделы 3.4, 3.4a, 3.5 (прочитай их перед началом). Правила репозитория: `CLAUDE.md`.

## Что сделать

1. Новый файл `Assets/Orbital/Core/Flight/CelestialProjection.cs`, namespace `Orbital.Core.Flight`.
   - Только engine-free C#: без `UnityEngine`, без `Debug.*`, без аллокаций в горячих функциях. Вектор — `Vec3` из `Core/Flight/Vec3.cs` (double). Стиль как в `SoiFrames.cs`/`NavBall.cs`: блиттабельные `struct` + `static` чистые функции, XML-комментарии на английском.
   - `struct ProjectionCamera`: `Vec3 Eye` (глобальная позиция глаза, м), `double HorizontalFovRad`, `int WidthPx`. Свойство/функция «угол на пиксель» = `HorizontalFovRad / WidthPx`.
   - `enum BodyDrawMode { Disk, Point }`.
   - `struct ProjectedBody`: `Vec3 Direction` (единичный, от глаза к центру тела), `double Distance` (м, до центра), `double AngularRadius` (рад, точный: `asin(R / d)`), `Vec3 ScaledPosition` (= `Direction * L`), `double ScaledRadius` (= `L * R / d`), `BodyDrawMode Mode`, `bool Inside` (глаз внутри тела или на поверхности, `d <= R`).
   - `static ProjectedBody Project(in ProjectionCamera cam, Vec3 bodyCenter, double bodyRadius, double scaledDistance, double minPixels)`:
     - `d = |bodyCenter - Eye|`; размещение на дистанции `L = scaledDistance` с радиусом `L * R / d` — угловой размер сохраняется точно (`asin(r/L) == asin(R/d)`).
     - Режим: `Point`, если `2 * AngularRadius / (угол на пиксель) < minPixels`, иначе `Disk`. Порог зависит от пикселей камеры, не от расстояния.
     - Вырожденные случаи без NaN/Infinity: `d <= R` → `Inside = true`, `AngularRadius = PI/2`, `Mode = Disk`, `ScaledRadius = L`; `d == 0` → `Direction` любой фиксированный единичный (например `Vec3.UnitY`). `R == 0` → точка с нулевым радиусом.
   - Константы по умолчанию: `DefaultScaledDistance = 1e5`, `DefaultMinPixels = 2.0`.

2. Новый файл тестов `Tools/OrbitMathTests/Stage3ViewTests.cs` (NUnit, как `Stage3SoiTests.cs`) и строка `<Compile Include="Stage3ViewTests.cs" />` в `Tools/OrbitMathTests/OrbitMathTests.csproj` (файлы `Core/Flight/*.cs` уже подключены маской). Тесты:
   - угловой размер сохраняется: для набора расстояний (от 1,01 R до 1e13 м) и радиусов (1e3..7e8 м) `asin(ScaledRadius / L)` совпадает с `asin(R/d)` с точностью 1e-9 рад;
   - Земля (R = 6.371e6) с расстояния 1 а.е. (1.496e11) и Солнце (R = 6.96e8) с расстояния 40 а.е.: все поля конечны, `(float)ScaledPosition.*` и `(float)ScaledRadius` конечны и не нулевые;
   - одно и то же тело и глаз: камера полёта (FOV 60°, 1920 px) даёт `Point`, телескоп (FOV 0.05°, 512 px) даёт `Disk` (подбери тело/расстояние так, чтобы это было верно, например Луна с 3.8e8 м не подходит — она диск в обоих; возьми Марс с 7.8e10 м);
   - `Direction` единичный (|len-1| < 1e-12), `ScaledPosition` = `Direction * L`;
   - вырожденные: глаз внутри тела, глаз в центре, `R = 0` — нет NaN/Infinity, ожидаемые поля.
