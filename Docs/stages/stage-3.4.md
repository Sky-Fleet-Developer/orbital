## Что сделано
- `Core/World.cs`: `Frames` (`WorldFrames.Build`, при ошибке null и лог) и `Definition` для источника `SharedFile`.
- `Core/Flight/SoiFrames.cs`: `GlobalPosition(i, t, local)`, `ApplyTo(string id, ref FlightParams)`.
- `Core/Net/Ghosts.cs`: `GhostView.GlobalDistance`.
- `Craft/CraftSpawner.cs`: тело спавна из таблицы по id, `Clock.Frames` и `parent` офлайн, таблица в `CraftNetLink` онлайн, `OnlineParams` по `ParentId` сервера; `PresentBody` перенастраивает вид при смене тела; навбол, опора на земле, телеметрия и HUD берут параметры текущего тела; HUD `@ Тело  SOI ...`; лог `SOI: a -> b at t=...`; хуки `ORBITAL_SPAWN_BODY` (офлайн) и `ORBITAL_AUTOBURN` (теперь и офлайн, через клавиши X/T/Z).
- `Craft/CraftPresenter.cs`: пул сфер всех невиртуальных тел (текущее тело всегда, остальные при поверхности ближе far), `SetBody`, сглаженный базис камеры V (tau 1 с реального времени), площадка и столбы только на теле старта.
- `Craft/GhostPresenter.cs`: 3D по глобальному расстоянию < 20 км, призрак у другого тела переводится в систему своего; `CraftNetLink.cs`: таблица у своего аппарата и призраков.
- Тесты: приёмочные `Stage3p4Tests.cs` (4), свои `Stage3p4ExtraTests.cs`.

## Что посмотреть в Editor (пользователь)
1. Офлайн: в `CraftSpawner` тело `Phobos` (поле `bodyName`, вид спавна Surface) или переменная окружения `ORBITAL_SPAWN_BODY=Phobos` перед запуском Unity. Взлёт вверх ~15-20 м/с: HUD `@ Phobos  SOI 16.9 km` → `@ Mars  SOI 577239.1 km`, в консоли `SOI: phobos -> mars`. Фобос остаётся виден сферой после смены; камера V доворачивается плавно, без рывка. Возврат к Фобосу (вход в SOI) и посадка, площадка снова видна. Enter — новый аппарат на Фобосе.
2. Онлайн: тот же переход (нужна точка старта на Фобосе на сервере или запуск с Земли — с Земли не улететь); строка Net — без жёстких коррекций при смене тела. Пока точки старта на Фобосе в `startpoints.json` нет (это 3.7), онлайн-проверку можно отложить.
3. Онлайн без своего аппарата (после крушения): HUD не должен показывать мусор (параметры теперь берутся у `Link.Params`).

## Одобренный дизайн (коротко)
- Таблица тел `BodyFrameTable` строится в `World.Load` (источник `SharedFile`) и отдаётся `World.Frames`/`World.Definition`; режим `Scene` — старое поведение без таблицы.
- `CraftSpawner`: тело спавна по id таблицы (`WorldFileLoader.IdOf`), офлайн `Clock.Frames` + `parent` в `CreatePlayerCraft`, онлайн `CraftNetLink` с таблицей, `OnlineParams` через `BodyFrameTable.ApplyTo(ParentId)`; при смене тела `CraftPresenter.SetBody`, лог `SOI: a -> b at t=...`.
- `CraftPresenter`: пул сфер всех невиртуальных тел (показ, если поверхность ближе far, текущий родитель всегда), позиции через глобальные состояния таблицы; камера V сглаживает весь базис (up/east/north) кватернионом, tau = 1 с реального времени; площадка и столбы только на теле точки старта.
- `GhostPresenter`: 3D для всех ближе 20 км по глобальному расстоянию (`GhostView.GlobalDistance`), позиция призрака у другого тела переводится в систему своего (`Convert`).
- HUD: `@ Тело`, радиус SOI («-» у корня). Подсказка о смене SOI — 3.4b.
- Хуки smoke: `ORBITAL_SPAWN_BODY` (офлайн, спавн на поверхности тела), `ORBITAL_AUTOBURN` офлайн.
- Engine-free API: `BodyFrameTable.GlobalPosition(i, t, local)`, `BodyFrameTable.ApplyTo(string id, ref FlightParams)`, `GhostView.GlobalDistance(frames, parentA, posA, parentB, posB, t)`.
