# Подэтап 3.2. Клиент: смена родителя у своего аппарата и у призраков

Статус: готов 2026-11-03 (координатор сам, без исполнителей). План: `Docs/Stage3-Plan.md`, раздел 3.2.

## Шаги
- [x] `BodyFrameTable.ApplyTo(i, ref FlightParams)`: гравитация и поверхность тела в параметры полёта; `SoiRule.Step` — правило после шага ядра, только в полёте, с заменой параметров.
- [x] `Propagation.Advance` с таблицей: правило после каждого шага (догон призраков, жёсткая коррекция).
- [x] `StateHistory`: тело у каждой записи (`HistorySample.Parent`), соседние записи разных тел смешиваются в системе старшей (`Frames.Convert`). Мягкий сдвиг одинаков во всех системах (системы отличаются только смещением).
- [x] `Reconciler.Compare(..., frames)`: серверное состояние у другого тела переводится в систему клиента на его время; `Hard("parent")` только для неизвестного тела или другого тела на земле. `ApplyHard(..., ref p, frames, out parent, ...)`: параметры тела сервера, догон с правилом.
- [x] `OwnCraftLink.Frames`, `Parent`, `ParentId`, `ParentChanges`: правило после шага, на смене родителя рекордер закрывает сегмент (`Flush`), жжение продолжается в новом с того же сэмпла.
- [x] `Ghost.Frames`: призрак ведётся у тела своего серверного состояния (свои `nu` и поверхность), меняет тело по правилу; `ParentId`; при смене тела в новом состоянии показанная точка переводится в систему нового тела.
- [x] Офлайн ECS: `SoiComponent`, `SoiSystem` (после `LandedSupportSystem`), `FlightClock.Frames`, `CraftSimulation.CreatePlayerCraft(..., parent)` и `Parent`; `ThrustRecorderSystem` закрывает сегмент на смене.
- [x] `Uplink.CopySegments` (просмотр очереди для проверок).
- [x] Тесты OMT `Stage3p2Tests` (6) и замер дрейфа.

Без таблицы (`Frames = null`) всё работает как раньше: Unity-клиент пока таблицу не передаёт, это подэтап 3.4 (там же `CraftSpawner`/`CraftNetLink`/`GhostPresenter` и вид).

- Призрак у Луны при своём аппарате у Земли: через 600 с совпадает с Кеплером вокруг Луны (< 5 м); призрак, уходящий из SOI Луны, меняет тело на Землю.

  - перелёт к Луне (перигей 300 км, апогей 384 000 км): 0.001 м.
