# Этап 2c.7: чужие аппараты, обломки, бот

Статус: код готов 2026-11-03 (координатор сам, без исполнителя); проверено тестами и smoke-прогоном плеера с ботами против настоящего сервера. **Ждёт проверки пользователя в Editor** вместе с 2c.6.

План: `Docs/Stage2c-Plan.md`, раздел 2c.7.

## Что сделано
- **Бот** `orbital-server/Tools/OrbitBot` (консоль, net8.0): `dotnet run` с аргументами `[count=3] [url] [--seconds N] [--world path]`. Каждый бот — тот же engine-free клиент (`NetSession` + `OwnCraftLink` по настоящему WebSocket), мир — серверный загрузчик `world.json`. Цикл: стоит 4-8 с, взлетает с вертикальной скоростью +6 м/с 3-8 с, снижается со скоростью -max(1, min(4, 0,2·высота)) до посадки; SAS и RCS включены; после крушения спавнится снова. Регулятор: дроссель зависания (вес / максимальная тяга) + 0,05·(нужная − текущая вертикальная скорость), рычаг ведётся пропорционально (он ходит со скоростью ThrottleRate = 0,25/с). Первый вариант (рычаг «туда-сюда») разбивался на посадке; с регулятором зависания 3 бота за 90 с: 13 прыжков, 0 крушений, 0 отказов, 0 коррекций.
- **`Craft/GhostPresenter.cs`**: чужие аппараты того же тела ближе 20 км — грейбокс (как свой, без пламени) в «плавающем» виде по разности double-позиций; остальные — в списке OTHERS (позывной, расстояние или тело, landed/crashed) внизу слева в HUD. Метки обломков: красный блок на земле в точке крушения (широта/долгота тела в радианах, `Surface.Point` на текущее время).
- **`CraftNetLink`**: призраки (`Ghost` из 2c.4: последнее серверное состояние, продлённое ядром, вид догоняет новое состояние за 0,5 с); `get_state` всех при входе и каждые 15 с; push `proximity_update` (через `NetSession.OtherState`); аппарат, о котором сервер молчит 45 с, забывается; по `wreck_created` призрак разбитого аппарата убирается сразу. Обломки: `get_wrecks` при первом опросе, push `wreck_created`, свой `craft_destroyed` с обломком. `OwnParent` — тело своего аппарата по последнему слову сервера.
- `Core/Net`: `MessageTypes.Wrecks`, `WrecksMessage`, `NetSession.RequestWrecks`, событие `WreckSeen`.
- `CraftPresenter`: наружу `Root`, `Materials`, `CgHeight`, `Layer`, `ToVector`/`ToQuaternion` (internal) для призраков.

## Не проверено
- **Метка обломка в кадре не видна**: обломок стоит точно в точке крушения, под своим разбитым аппаратом (он остаётся нарисованным до нового спавна). Проверить в Editor: после DESTROYED нажать Enter, отлететь — у площадки должен быть красный блок.
- Призраки в полёте вблизи (дрожание, догоняние вида), призраки на других телах (только список), много аппаратов (производительность продления ядром по 0,02 с на кадр).
- Призрак уничтоженного чужого аппарата убирается сразу по `wreck_created` (обломок несёт `craftId`); в smoke не наблюдалось (боты не разбивались).
