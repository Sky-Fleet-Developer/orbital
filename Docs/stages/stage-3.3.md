- `Propagator.cs`:

Старая перегрузка (одно тело, без правила) осталась для тестов 2a.
  - `Propagator.IntegrateBurn` / `BodyOf`: одна функция для проверки манёвра и для состояния внутри жжения, поэтому обе видят одни и те же переходы.

## Не проверено
- Пролёт сквозь SOI тела, которое меньше пути за шаг сервера (0,5 с): у самых малых тел при больших скоростях сервер может проскочить сферу, а клиент (шаг 0,02 с) — нет; тогда спасает жёсткая коррекция. Для тел мира (минимум SOI 16,9 км у Фобоса) это скорости выше ~30 км/с, недостижимо.
- Вертикальная траектория (`Radial`) после жжения по-прежнему не ищет вход в SOI ребёнка (известное ограничение 1.x, план 3, п. 1.1).
- `nextTransition` в состоянии для HUD не добавлен; решение пользователя 2026-11-03: временная подсказка в HUD в 3.4 (дальше её заменят панель планирования и глобальная карта).
